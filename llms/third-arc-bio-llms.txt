# Third Arc Bio

> Clinical-stage biotechnology company developing multifunctional antibodies that build immune
> synapses to precisely activate or inhibit T cells. Platforms: ARCStim (solid tumors) and ARCTag
> (immunology & inflammation). Lead program ARC101, a bispecific T-cell engager, is in Phase 1 in
> patients with CLDN6-expressing solid tumors.

## Developer surface

Third Arc Bio publishes NO public API. As of 2026-08-30 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL/Protobuf/WSDL contract, no SDK or package in any public
registry, no MCP server, no A2A agent card, and no /.well-known/ document on thirdarcbio.com.
The only host that resolves is thirdarcbio.com (a Gatsby static site backed by Sanity CMS);
api., developer., docs. and mcp. subdomains do not resolve. This is an honest zero, not a gap in
our probing — therapeutics, not software, is the product.
